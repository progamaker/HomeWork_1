# Решение ДЗ 2: сканер документов

`docscan.py` реализует все 13 функций задания. Условия и исходный шаблон находятся в соседних `README.md` и `template/` каталога `hw2-docscan`.

## Запуск

Нужен Python 3.11 или новее. Из этой папки:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest tests -q
python docscan.py scan sample_data/corner.jpg --canny 50,150 -o out/example.jpg --bw out/example_bw.png
```

Для полного повторения приложенных измерений:

```bash
python reproduce.py
```

Отчёт: `REPORT.md`. Результаты: `out/`. Примеры курса: `sample_data/` — это синтетические сцены, они **не заменяют собственный набор** из 18 фотографий. Запись `out/video.mp4` получена из ролика курса; обязательную запись с камеры нужно сделать отдельно.

## Как работает код

1. `estimate_noise`: отклик ядра имеет стандартное отклонение 6σ. Медиана абсолютного отклика устойчива к тексту и делится на 0.6745·6.
2. `denoise`: из требуемого остатка шума выбирается σ гауссова фильтра, ограниченная диапазоном 1–3.
3. Закрытие изображения подавляет тёмные буквы. `auto_canny` вычисляет пороги по медиане; CLI позволяет использовать фиксированные пороги.
4. Контурный путь ищет выпуклый четырёхугольник среди крупнейших замкнутых контуров.
5. Путь Хафа преобразует отрезки в точки, затем последовательный RANSAC выделяет четыре прямые. На каждой итерации случайная пара задаёт гипотезу, лучшая уточняется по инлаерам методом наименьших квадратов. Удаляются также соседние точки, чтобы не выделить одну сторону дважды.
6. `quad_from_lines` перебирает три разбиения четырёх прямых на пары противоположных сторон; проверяет пересечения, выпуклость и площадь.
7. Углы упорядочиваются по полярному углу относительно центра. В координатах изображения ось y направлена вниз, поэтому возрастающий угол соответствует обходу по часовой стрелке.
8. Гомография выпрямляет лист. Размер с известным отношением сторон выбирается так, чтобы не сокращать ни одну наблюдаемую сторону.
9. Деление на медианный фон компенсирует плавное изменение освещения; затем Otsu отделяет текст от бумаги.
10. IoU — доля пересечения двух заполненных масок в их объединении. Отказ детектора оценивается отдельно для негативных кадров.
